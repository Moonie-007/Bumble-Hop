# Bumble Jump

## Overview
Bumble Jump is a browser-based, Doodle Jump-inspired game developed using HTML, CSS, and JavaScript. The player controls Bumble, a character that automatically jumps between platforms while attempting to climb as high as possible.

## Features
Automatic jumping and gravity-based movement
Horizontal movement using keyboard controls
Screen wrapping when moving beyond the left or right edges
Randomly generated platforms
Score tracking based on upward progress
Pixel-style score display
Automatic restart when the player falls off the screen

## Controls

## Key Action
Left Arrow, A,  to move left
Right Arrow ,D ,to move right

## Tech Stack
- HTML5
- CSS3
- JavaScript
- HTML Canvas API

## Installation and Setup
1. Clone or download this repository.
2. Ensure all project files, including the HTML, CSS, JavaScript, and image assets, are in the appropriate directory.
3. Open the HTML file in a modern web browser.
4. Use the keyboard controls to play.
